# SMARTA Chat (Flutter Frontend)

A simple chat UI for the SMARTA maintenance assistant. It talks to the
SMARTA backend (`../api.py`) over HTTP.

## 1. Start the backend first

From the `SMARTA/` project root:

```bash
pip install -r requirements.txt
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

This exposes:
- `GET  /health` — liveness check
- `POST /chat`   — `{"question": "..."}` -> `{"answer": "..."}`

Ollama must be running locally with the `qwen2.5:3b` model pulled, since
`rag/generator.py` calls it directly (`ollama pull qwen2.5:3b`).

## 2. Set up the Flutter project

This folder already contains `pubspec.yaml` and `lib/main.dart` — the
actual chat UI. It's missing the platform scaffolding (`android/`, `ios/`,
`web/`, etc.) because those are generated by the Flutter SDK, which isn't
available in the environment this was built in. Generate them with:

```bash
cd flutter_app
flutter create .
flutter pub get
```

`flutter create .` will safely add the missing platform folders without
touching your existing `pubspec.yaml` or `lib/main.dart`.

## 3. Run the app

```bash
flutter run
```

Pick any target (Chrome, an Android emulator, a connected device, or
desktop). On first launch, tap the settings icon (top-right) to set the
correct backend address if the default doesn't work for your platform:

| Target                  | Backend URL              |
|--------------------------|---------------------------|
| Chrome / macOS / Windows/ Linux desktop | `http://localhost:8000` |
| Android emulator          | `http://10.0.2.2:8000`   |
| iOS simulator             | `http://localhost:8000` |
| Physical phone (same Wi-Fi) | `http://<your-computer-LAN-IP>:8000` |

## What it looks like

- Chat bubbles: your questions on the right, SMARTA's answers on the left.
- A "SMARTA is thinking…" indicator while the request is in flight.
- Errors (backend down, bad response) show as a red bubble instead of
  crashing the app.
- Settings icon in the app bar lets you change the backend URL at runtime
  without rebuilding the app.

## Files

- `lib/main.dart` — the entire app (single-file, easy to extend).
- `pubspec.yaml` — dependencies: `http` for networking, `cupertino_icons`
  for icons.
